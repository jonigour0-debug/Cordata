# Cordata
It's a physical project like hardware 


🤖 CORDATA — Voice Controlled AI Robot Car

CORDATA is a smart robotic car designed to interact with humans through voice commands, movement, camera vision, and AI-powered conversations.

The goal of CORDATA is to create a friendly and intelligent robot that can listen, respond, move, and explore its surroundings.

🚀 Project Features

- 🎙️ Voice-controlled movement
- 🧠 AI-powered conversation
- 📷 Camera for visual awareness
- 🖥️ Display screen for information
- 🔊 Text-to-speech communication
- 🚗 Forward, backward, left, and right movement
- 🛑 Obstacle detection and safety stop
- 📱 Smartphone-based control
- 🔌 Modular hardware design

🛠️ Hardware Components

Component| Purpose
ESP32 Development Board| Main controller
Motor Driver| Controls DC motors
DC Gear Motors| Robot movement
Robot Chassis| Mechanical body
Bluetooth| Wireless communication
Ultrasonic Sensor| Obstacle detection
Camera Module| Visual input
OLED Display| Information display
Battery Pack| Power supply
